# HIVECAST

全新的桌面端直播录制应用。目标：在一个本地 GUI 应用里完成「多平台直播间监听 → 自动录制 → 弹幕记录 → 后处理（修复/转封装/封面/云上传）→ 归档管理」的全流程。

本目录是 HIVECAST 的唯一交付位置：源码、文档、数据、构建产物都在 `HIVECAST/` 之下。

## 参考项目

| 项目 | 语言 | 定位 | 在本项目中的作用 |
| --- | --- | --- | --- |
| `bililive-go/` | Go（后端）+ React（Web UI） | 常驻服务式直播录制器 | 领域模型、监听/录制状态机、平台适配器、配置分层、后处理流水线的主要参考 |
| `streamlink/` | Python（CLI + 库） | 取流库 + 播放器前端 | 流抽象（HLS/DASH/HTTP）、分段下载与缓冲、清晰度权重/选择、插件体系的主要参考 |
| `biliLive-tools/` | TypeScript（Electron + Vue3） | 桌面端多平台录制 + 弹幕 + 上传一体化工具 | **产品形态最接近的参考**：取流/录制/下载三段切分、线路分组、弹幕落盘、任务队列、桌面端工程化（GPL-3.0，只读设计不拷代码） |

## 快速开始

```bash
pnpm install      # 首次
pnpm tauri dev    # 起前端 + 编译 Rust + 打开窗口
pnpm build        # 前端类型检查与构建
```

需要本机已安装 ffmpeg（macOS 建议 `brew install ffmpeg`）。

## 目录约定

```text
HIVECAST/
├── README.md            本文件
├── docs/                架构、接入与阶段文档（含 assets/ 截图）
├── src/                 前端（React + Vite + Tailwind）
├── src-tauri/           Rust 侧（Tauri 外壳、IPC 契约、本地流服务）
├── assets/              图标源文件、字体、内置工具清单
├── scripts/             绑定生成、文档与文案校验
└── data/                运行期数据（配置、数据库、录制产物），不入版本库
```

运行期数据不写仓库：开发态在系统缓存/应用数据目录（macOS 为 `~/Library/Caches/com.hivecast.desktop` 与 `~/Library/Application Support/com.hivecast.desktop`），录制产物落在媒体库 `~/Movies/HIVECAST`。
