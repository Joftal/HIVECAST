# 112-观看弹幕工具栏面板复刻

> 状态：v1 已实施（2026-11-09）；浏览器预览已复看主面板和高级设置面板。
> 范围：观看页直播播放器的弹幕设置入口、主面板、高级设置与 Canvas 渲染参数。

## 0. 结论速览

- 弹幕设置从播放器内的大段 JSX 抽成 `DanmakuSettingsPanel`，主面板与高级面板共用同一个 298px 锚点。
- 尺寸对齐 B 站直播：298px 宽、20px 横向内边距、37px 滑杆行、40px 底部入口、2px 圆角。
- 主面板包含显示区域、弹幕密度、不透明度、字体大小、弹幕速度、弹幕随屏幕缩放和高级设置。
- 高级设置补齐弹幕字体、粗体、描边类型和恢复默认，不再只是占位入口。
- 项目粉色替换为 HIVECAST 的蓝色 + 黄色组合：滑杆与选中描边用蓝色，密度选中和勾选文字跟随主题。

## 2. 主题色映射

面板保持 B 站的深色浮层形态，不跟随应用页面变成浅色卡片；强调色使用项目 token 对应色：

| 用途 | 颜色 |
| --- | --- |
| 滑杆已填充轨道、勾选框、当前描边选项 | 项目蓝 `#2f6bff` |
| 密度当前项、勾选文字、滑块细描边（浅色主题） | 项目蓝 `#2f6bff` |
| 密度当前项、勾选文字、滑块细描边（深色主题） | 项目黄 `#f0a23c` |
| 标签与辅助信息 | 白色 72% |
| 主信息与数值 | 白色 94% |

面板本身始终保持 B 站式深色，但选中文字和勾选提示跟随应用实际主题：浅色主题为蓝色，深色主题为黄色。避免整个弹幕面板退回 B 站粉色。

## 3. 高级设置

高级设置从主面板右侧进入，左上角返回，结构与 B 站一致：

- 弹幕字体：黑体 / 宋体 / 楷体。
- 粗体：布尔开关。
- 描边类型：重墨 / 描边 / 45°投影。
- 恢复默认设置。

这些选项已接入持久化弹幕偏好与 Canvas 渲染：

- `fontFamily` 决定绘制字体族。
- `bold` 决定 400 / 700 字重。
- `outline` 决定描边粗细，或 45°投影的偏移与阴影。

- 高级面板实测 298×222px，返回、下拉、粗体、描边分段与恢复默认均可见。
- `pnpm exec tsc -b`、`pnpm build` 通过。

## 5. 已知限制

- 面板固定为 B 站式深色玻璃，不跟随应用浅色页面变成浅色。
- 宋体 / 楷体依赖系统字体；缺少对应字体时由 CSS 回退到系统衬线字体。
- 高级设置实现了当前 Canvas 能表达的字体、粗体与描边三项，不额外引入 B 站账号级弹幕过滤规则。
