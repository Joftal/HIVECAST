## 1. 通知：一个事件，六种 kind

上一轮的通知只服务录制，事件名 `record://notice`、类型 `RecordNotice`，但观看失败和登录失效同样需要「系统通知」这条通道。这次把它泛化成应用级播报：

| kind | 触发点 | host_name | detail |
| --- | --- | --- | --- |
| `started` | 开录 | 房间名 | — |
| `ended` | 下播/停录 | 房间名 | — |
| `failed` | 录制异常 | 房间名 | 错误文本 |
| `disk_full` | 保留策略/磁盘满 | 房间名 | — |
| `view_failed` | 观看槽位放弃重连 | 房间名 | 最后一次错误 |
| `credential_expired` | 启动复验发现登录失效 | 账号名 | `bilibili` |

设计取舍：

- **文案仍然只在前端**。后端只给 kind + 名字 + detail，前端按 `notice.<kind>.title/body` 组装，切语言即时生效，后端不引入任何 UI 字符串。
- **事件名一起改**。只改类型不改事件名会留下「名字叫 record 却发观看事件」的错位；改名成本只有 `ipc.ts` 一处常量与 `App.tsx` 一个函数名，顺手改掉。
- **不合并到「通知中心」**。v1 没有站内通知面板，系统通知即全部；等有站内列表时再引入 notice 表，现在的 `AppNotice` 正好是它的行结构。

## 2. 观看失败通知：只在「放弃」时弹

监督循环里有两个终态分支会写 `status = error`：

1. 子进程反复退出（`Cycle::Exited`）且 `attempts > MAX_RETRIES`（10 次）；
2. 取流/起播直接报错（`Err`）且超过重试上限。

两处都调 `notify_failure(app, room, detail)`，`detail` 就是槽位里显示的同一句话（「转封装多次失败，已停止重连」或平台错误文本）。

中间态（`reconnecting` 与倒计时）**不弹**：一次网络抖动不该在系统通知中心留一条记录；用户盯着屏幕时槽位本身已有橙色倒计时。真正需要离开屏幕也知道的是「这一格不会自己好了」。

## 3. 登录态过期通知：只在状态翻转时弹

`account::revalidate` 在启动时异步跑一次（网络慢不拖启动）。失败时把 credential 标成 `expired`，并比较 **改之前** 的 `row.status`：

- `ok → expired`：播报 `credential_expired`，body 提示去设置里重新扫码；
- 已经是 `expired`：只落库不播报，否则每次冷启动都弹一次，用户会关掉通知权限。

没有做成「定时复验」：B 站 Cookie 有效期以月计，启动一次足够；真到开录失败时，录制链路自己的错误会带 401/未登录文案。

## 4. 媒体库合并：只合并选中的那几段

后端原本已有 `room_merge_sessions(room_id)`，语义是「把这个房间最近 200 场里所有已完成的录像全合并」。接到 UI 上会变成「点一下把该房间历史全并了」，不可控。新增 `sessions_merge(session_ids)`：

- 先校验 `len >= 2`，再把每段取出来；**任一段还在录制就整体拒绝**（「有录像还在录制，先停下再合并」），不做部分合并。
- 排序只看 `started_at`，与勾选顺序无关；`file_path` 为空或文件已被删掉的跳过，最终不足 2 段则报错。
- 产物由 `postprocess::merge` 走 concat，返回 `PostResult{kind:"merge"}`；媒体库列表**不新增条目**（合并产物不在 DB 里），所以前端只弹一条「已合并：{{size}}」，需要的话用 Finder 定位原目录。
- 选中的段可以跨房间：按时间排序后就是一条时间线，适合「同一直播间中途重启导致的两段」。

单测 `merge_order_follows_start_time_and_skips_missing` 覆盖三件事：乱序传入按开录时间排、缺失文件被跳过、顺序与入参无关。

## 6. 剩余缺口

| 缺口 | 影响 | 建议 |
| --- | --- | --- |
| 媒体库没有统一音量 | 想听某条要点两次（卡片各自静音） | 工具栏加总音量，卡片默认跟随 |
| 后处理无进度百分比 | 大文件 remux 只有转圈 | `ffmpeg -progress` + 事件推送 |
| 回放缓存等于录像体积 | 3 条 4 小时同时回放 ≈ 3 倍磁盘 | 滑窗分段（只保留播放点前后 N 分钟） |
| 观看端不能选线路 | 线路菜单只在录制侧 | `ViewSlot` 加 `line`，`open/retry` 透传 |
| 扫码过期无倒计时 | 要手点「刷新二维码」 | 用 poll 返回的有效期起倒计时 |
| Cookie 明文落库 | 数据库被拷走等于登录态泄露 | 接 Keychain / DPAPI 的加密层 |
| 未从 dmg 安装验收 | 只跑了 `.app` | 出包后手动装一遍 |
