# 105-录制详情抽屉重构与播放叠层

> 状态：v1 已实施（2026-11-09）；前端编译与构建通过，真实窗口的悬浮播放叠层与抽屉滚动待复看。
> 范围：监控页「录制详情」抽屉：封面播放叠层、移除底部关闭按钮与最近录制列表、重排信息/设置的结构与控件。
> 前置阅读：`101-监控列表细节优化.md`、`103-监控页性能与加载优化.md`、`104-监控选择工具栏改用Arc-FloatingButtonGroup.md`。

## 0. 结论速览

- 封面在可播放（直播中或录制中）时，悬停/键盘聚焦出现深色遮罩 + 圆形播放按钮，并带轻微图片放大。
- 右下角「关闭」按钮移除；关闭入口保留为标题栏 ×、点击遮罩和 `Escape`。
- 抽屉统一为「标题栏 → 封面 → 直播间信息 → 录制设置」四段，卡片圆角、行高和分隔线一致。
- 主播信息从头像 + 名称一行展示；分区/画质/已录/最近录制改为标签-值信息卡。
- 「最近录制」列表、合并入口、分页加载全部移除；抽屉只通过 `session_summary` 取一次总体积填充「已录」。

## 1. 封面播放叠层

```tsx
<button className="group relative ...">
  <Thumb ... />
  {playable ? (
    <span className="pointer-events-none absolute inset-0 ... group-hover:bg-black/25 group-hover:opacity-100 group-focus-visible:opacity-100">
      <span className="flex h-11 w-11 items-center justify-center rounded-full bg-black/55 ring-1 ring-white/25">
        <PlayIcon />
      </span>
    </span>
  ) : null}
</button>
```

- 只有 `room.isLive || isRecording` 时显示，避免给禁用状态一个可点击的错觉。
- 悬停时封面图片 `scale(1.02)`，`overflow-hidden` 裁切；减少动态偏好由全局 CSS 降为 1ms。
- 叠层 `pointer-events-none`，点击仍由外层按钮处理；按钮补 `aria-label` / `title` 为「观看」。
- 键盘焦点进入时同样显示遮罩和播放按钮。

## 2. 移除底部关闭

- 删除 `<aside>` 底部的 footer 与「关闭」按钮，也删除不再使用的 `monitor.close` i18n key。
- 关闭方式保留：
  - 标题栏右上角 ×（`closeDetail`）；
  - 点击抽屉外的遮罩；
  - `Escape`。
- 抽屉内容区继续 `flex-1 overflow-auto`，删除 footer 后滚动区域延伸到窗口底部。

## 3. 布局与控件

### 标题栏

- 标题「录制详情」+ 平台名作为副标题，不再显示主播名（主播信息移到正文，避免重复）。
- 关闭 × 增加 `shrink-0`，长平台名不会挤压按钮。

### 封面与标题

- 封面保持 16:9、8px 圆角。
- 状态行增加颜色圆点（录制红 / 直播绿 / 离线灰），后面跟开播时间。
- 房间标题改为 15.5px `h3`；主播行使用 20px `Avatar` + 名称；链接单独一行、截断并保留 `title`。

### 直播间信息

- 新 i18n key `monitor.roomInfo`（直播间信息 / Room info）。
- 标签-值四行：分区、画质、已录、最近录制。
- 卡片 `rounded-[8px] border border-line`，行间 `border-t`，标签固定 72px，值右对齐并截断。

### 录制设置

- 画质、线路两行放进同一张卡片，标签宽度与信息卡一致（72px）。
- 「加载可用线路」从裸文本改为带刷新图标的行内链接，仍在 `lines === null` 时显示；空线路提示与加载中状态保留。

### 移除最近录制列表

- 删除「最近录制」标题、总数、合并按钮、列表行与「加载更多」。
- 抽屉打开时只调用 `sessionSummary(roomId)` 取 `totalBytes`，不再调用 `sessions_list`。
- 同步删除 `drawerSessions`、分页/加载状态、`doPost`、`roomMergeSessions` 引用，以及 `monitor.sessions`、`monitor.noHistory`、`monitor.loadMore`、`monitor.post.*` 文案。
- 录制历史查看与合并统一走媒体库，详情抽屉只保留「已录」总体积。

## 4. 验证

- `pnpm exec tsc -b`、`pnpm build` 通过。
- `check:i18n` 641 keys（新增 `roomInfo`，移除 `close` 与录制列表相关文案）、`check:docs` 106 files 通过。
- 覆盖状态：直播中显示 LIVE、录制中显示 REC、离线且未录制封面禁用且无播放叠层。
- 待真实窗口复看：悬停播放按钮大小、封面放大裁切、信息卡行高、移除列表后的抽屉滚动长度。

## 5. 已知限制

- **抽屉不再展示录制列表**：查看、删除、合并历史录像请到媒体库；「已录」仅显示该房间总体积。
- **封面叠层只服务直播观看**：离线房间的封面仍不可点击，历史录像入口仍在媒体库。
- **线路加载入口只在未加载时出现**：线路加载成功后不再显示刷新动作，沿用原有行为。
- **抽屉无固定 footer**：关闭仍靠右上角 ×、点击遮罩或 `Escape`。
