# 105-录制详情抽屉重构与播放叠层

> 状态：v1 已实施（2026-11-09）；前端编译与构建通过，真实窗口的悬浮播放叠层、当前录制卡与监控开关待复看。
> 范围：监控页「录制详情」抽屉：封面播放叠层、移除底部关闭与最近录制列表、主操作区、当前录制卡、监控状态与信息卡重排。
> 前置阅读：`101-监控列表细节优化.md`、`103-监控页性能与加载优化.md`、`104-监控选择工具栏改用Arc-FloatingButtonGroup.md`。

## 0. 结论速览

- 封面在可播放（直播中或录制中）时，悬停/键盘聚焦出现深色遮罩 + 圆形播放按钮，并带轻微图片放大。
- 右下角「关闭」与「最近录制」列表都移除；关闭入口保留为标题栏 ×、点击遮罩和 `Escape`。
- 抽屉结构：标题栏 → 封面 → 状态/标题/主播/链接 → 主操作 → 当前录制（仅录制中）→ 监控 → 直播间信息 → 录制设置。
- 主操作区提供「观看 / 开录或停录 / 刷新」，录制中额外显示当前场次卡（时长、实际画质/线路、文件名、打开文件夹）。
- 监控区提供自动录制开关、监控开关、最近检查相对时间与最近错误，错误可一键复制。
- 「已录」显示 `总体积 · N 场`，仍由 `session_summary` 提供，但不再请求 `sessions_list`。
- 设置区新增「观看画质」；线路行常驻刷新按钮；上次录制显示时间 + 时长，并可打开文件夹。

## 1. 封面播放叠层

```tsx
<button className="group relative ...">
  <Thumb ... />
  {playable ? (
    <span className="pointer-events-none absolute inset-0 ... group-hover:bg-black/25 group-hover:opacity-100 group-focus-visible:opacity-100">
      <span className="flex h-11 w-11 items-center justify-center rounded-full bg-black/55 ring-1 ring-white/25">
        <PlayIcon />
      </span>
    </span>
  ) : null}
</button>
```

- 只有 `room.isLive || isRecording` 时显示，避免给禁用状态一个可点击的错觉。
- 悬停时封面图片 `scale(1.02)`，`overflow-hidden` 裁切；减少动态偏好由全局 CSS 降为 1ms。
- 叠层 `pointer-events-none`，点击仍由外层按钮处理；按钮补 `aria-label` / `title` 为「观看」。
- 键盘焦点进入时同样显示遮罩和播放按钮。

## 2. 移除底部关闭与最近录制列表

- 删除 `<aside>` 底部的 footer 与「关闭」按钮，也删除不再使用的 `monitor.close` i18n key。
- 删除「最近录制」标题、总数、合并按钮、列表行与「加载更多」。
- 抽屉打开时只调用 `sessionSummary(roomId)` 取 `totalBytes`，不再调用 `sessions_list`。
- 同步删除 `drawerSessions`、分页/加载状态、`doPost`、`roomMergeSessions` 引用，以及 `monitor.sessions`、`monitor.noHistory`、`monitor.loadMore`、`monitor.post.*` 文案。
- 录制历史查看与合并统一走媒体库，详情抽屉只保留「已录 + 场次」汇总。
- 关闭方式保留：标题栏右上角 ×（`closeDetail`）、点击遮罩、`Escape`。
- 抽屉内容区继续 `flex-1 overflow-auto`，删除 footer 后滚动区域延伸到窗口底部。

## 3. 布局与控件

### 标题栏

- 标题「录制详情」+ `平台名 · 房间号` 作为副标题；主播信息在正文，避免重复。
- 关闭 × 增加 `shrink-0`，长副标题不会挤压按钮。

### 封面与标题

- 封面保持 16:9、8px 圆角。
- 状态行增加颜色圆点（录制红 / 直播绿 / 离线灰），后面跟开播时间。
- 房间标题改为 15.5px `h3`；主播行使用 20px `Avatar` + 名称。
- 链接单独一行、截断并保留 `title`，右侧提供复制按钮（`common.copy` / `common.copied`）。

### 主操作区

三列：观看、开录/停录、刷新。

- 「观看」用 primary；离开播且未录制时禁用。
- 「开录 / 停录」根据 `view.recording` 切换文案和 `recording` 红色样式；录制中仍可停录。
- 「刷新」复用 `roomRefresh`，成功后提示 `monitor.refreshed`。
- 观看/录制按钮分别显示 `busyAction` 对应的 loading，避免重复点击。

### 当前录制卡

仅 `view.recording` 存在时显示：

- 左侧红点 + `LiveDuration` 实时时长。
- 下一行显示实际画质与线路（空线路回退「自动」）。
- 底部一行显示文件名，右侧文件夹按钮调用 `mediaReveal(recording.sessionId)`。
- 卡片使用 `border-rec/20` 和 `bg-rec/5` 与普通信息卡区分。

### 监控

- 自动录制：Arc Switch；切换调用 `roomSetAutoRecord`，成功提示开/关。
- 监控：Arc Switch，`checked = !room.monitorPaused`；关闭后显示「已暂停监控」。
- 最近检查：`room.lastCheckedAt` 用 `Intl.RelativeTimeFormat` 显示「12 秒前 / 3 分钟前」，`title` 保留完整时间。
- 最近错误：`view.error` 存在时占一行，最多两行截断，完整内容放 `title`；右侧复制按钮复用 `common.copied`。

### 直播间信息

- 标签-值四行：分区、在线、录制画质、已录；已录显示 `体积 · N 场`（`SessionSummary.total`）。
- 上次录制单独一行：`datetime · 时长`（`lastSessionDurationMs`），右侧文件夹按钮调用 `mediaReveal(lastSessionId)`。
- 在线取 `room.online` + `compactNumber`；离线显示「—」。
- 卡片 `rounded-[8px] border border-line`，行间 `border-t`，标签固定 72px，值右对齐并截断。

### 录制设置

- 录制画质、观看画质、录制线路三行放进同一张卡片，标签宽度与信息卡一致（72px）。
- 观看画质复用 `roomSetQuality(id, recordQn, viewQn)`，与录制画质分开保存。
- 线路行右侧常驻刷新按钮：加载中显示 spinner，加载后仍可重新解析；空线路提示保留。

## 5. 已知限制

- **当前录制不显示实时文件大小**：数据库只在收尾时写最终大小，本轮不额外轮询文件系统。
- **打开文件夹依赖文件已创建**：`mediaReveal` 会校验路径存在，刚开录的瞬间可能提示文件不存在。
- **最近检查时间不逐秒刷新**：只在页面因房间事件或操作重渲染时更新。
- **没有下次检查倒计时**：监控调度含退避，前端没有可靠的单房间下次执行时间。
- **抽屉不再展示录制列表**：查看、删除、合并历史录像请到媒体库；「已录」显示总体积与场次。
- **复制链接/错误依赖 WebView 剪贴板权限**：失败时走 error toast。
- **抽屉无固定 footer**：关闭仍靠右上角 ×、点击遮罩或 `Escape`。
