# 111-观看侧边栏重构与槽位计数清理

> 状态：v1.1 已实施（2026-11-09）；前端编译与构建通过，真实窗口的侧栏宽度/空态布局待复看。
> 范围：观看页顶部工具栏、0 路空态、右侧候选直播间面板与添加直播间入口；移除 `0 / 4` 槽位计数，重排侧栏与空态层次，并与监控页共用添加弹窗。
> 前置阅读：`42-观看页布局设计.md`、`43-M17-观看页布局.md`。

## 0. 结论速览

- 顶部工具栏、侧栏面板标题、右侧收起栏的 `0 / 4` / 数量全部移除。
- 顶部工具栏整体移除：布局、紧凑、全屏收进右侧 48px 候选竖条的底部控制组，紧凑/全屏常驻（0 路空态也显示），视频区从内容区顶部直接开始。
- 移除页面级「弹幕设置」「全部静音」：音量在各播放器内调节，弹幕观感设置改为播放器内的浮层卡片。
- 播放器控制条按 B 站网页直播复刻：56px 渐变、左播放组/右画质工具组、竖向音量、298px 弹幕设置浮层；播放器浮层统一主题玻璃，选中态使用应用 accent。
- 0 路空态整合到一个卡片内：左侧说明与「添加直播间」，右侧紧凑直播列表；空列表/无直播也在同一张卡里表现。
- 侧栏从 300px 调到 320px，结构统一为：标题栏 → 搜索 → 提示 → 「可添加」列表 → 底部添加区。
- 列表行改成 28px 头像 + 两行信息 + chevron，hover 背景更明确；去掉主播名前的绿色圆点。
- 搜索框加图标与清空按钮；空列表有独立空态图标。
- 右侧收起栏改为 48px，头像列 + 底部方向按钮，不再显示候选数量。
- 「放入哪一格」浮层同步放大到 224px，标题与按钮圆角/间距统一。

## 1. 移除槽位计数

- 顶部工具栏：删除 `{count} / 4`。
- 面板标题：删除 `{count} / 4`，改为标题 + 说明。
- 右侧收起栏：删除候选数量 `{candidates.length}`。
- 槽位上限仍由 `MAX_SLOTS = 4` 控制；满 4 路时仍提示 `watch.slotsFull`，只是不再常驻显示数字。

## 2. 侧栏结构

```text
标题栏     直播间 / 选择直播间，悬停后放入格子          ×
搜索       搜索图标 + 输入框 + 清空按钮
提示       悬停直播间，选择要放入的格子
分区       可添加
列表       头像 / 标题 / 主播 / chevron
底部       添加直播间（整宽主按钮 → 监控页同一弹窗）
```

- 宽度：`w-[320px]`。
- 面板背景使用实色 `bg-surface`，左侧 1px 边框，阴影沿用 `shadow-2xl`。
- 标题栏 `px-4 py-3.5`，标题 13px semibold，说明 11px faint。
- 搜索框统一为 Arc `SearchField`：隐藏可视 label（保留无障碍名称）、搜索图标、带预留槽位的清除按钮与清除后回焦；侧栏内占满宽度，监控/媒体工具栏内固定 228px，设置面板也使用同一组件。
- 列表行 8px 圆角、`px-2.5 py-2`，hover `bg-raised`。
- 「可添加」列表改用 Arc `ScrollArea`（垂直、overlay 滚动条、上下边缘渐隐）：超出高度时在列表内部滚动，不挤动标题/搜索/底部按钮，也不再依赖 `scrollbar-gutter`。
- 列表头像 28px，fallback 用主播名首字母。
- 底部添加区独立 `border-t + bg-raised/25`，与列表分开。

## 3. 右侧收起栏

- 宽度 44 → 48px。
- 候选头像 24 → 28px，`ring-2 ring-surface`。
- 移除候选数量；候选区仍是切换面板的按钮，底部保留 28px 的方向按钮。
- 竖条底部新增独立控制组（`border-t` 分隔）：紧凑、全屏始终显示（0 路空态也保留），布局按钮仅在 2 路以上出现；布局菜单在竖条左侧弹出。
- 观看页根容器加 `overflow-hidden`：全屏时竖条 `translate-x-full` 与候选面板阴影不再撑出横向滚动，界面不能左右拖动。
- 全屏竖条悬停滑出延迟 140ms、过渡 150ms；右边缘热区与常规竖条同宽（48px）；候选面板或布局菜单打开时竖条保持显示，不会在操作途中滑走。
- 面板与竖条改用实色 `bg-surface`，不再对播放中的视频做 `backdrop-blur`；候选列表改用 Arc `ScrollArea`，滚动条以浮层形式出现。
- 面板打开时用 `animate-sheet` 轻量滑入，只动 transform/opacity，不触发重排。

## 4. 放置浮层

- 宽度 208 → 224px，圆角 10px，内边距 10px。
- 标题从大写淡字改为 11px 中等字重。
- 格子按钮圆角 8px、grid gap 2，保留「第 N 格 / 新增一格」。
- 位置计算同步从 `picker.x - 204` 调到 `-220`。

## 5. 工具栏与 0 路空态

### 工具栏

- 页面顶部不再有工具栏；视频区从内容区顶部直接开始。
- 布局、紧凑、全屏收进右侧 48px 候选竖条的底部控制组，与候选头像同属一列：
  - 紧凑与全屏固定显示：候选面板收起/展开、0 路空态都保留，默认可见。
  - 2 路以上额外显示布局按钮，点击在竖条左侧弹出布局菜单（当前版式打勾）。
  - 紧凑按钮切换格子间距，按下时高亮；全屏按钮切换全屏，全屏时竖条仍从右边缘 48px 热区悬停滑出。
- 移除页面级「弹幕设置」和「全部静音」：音量在各播放器左下角单独调节；弹幕观感设置移入播放器内部，由控制条上的设置按钮打开浮层。
- 1 路时竖条显示紧凑/全屏与候选直播间，不再有布局入口。

### 0 路空态

- 一个卡片内左右分栏：左侧空态插画、标题、说明和「添加直播间」按钮；右侧「直播中」列表。
- 左侧整列水平/垂直居中：插画 44px，标题 15px，说明 11.5px / 行高 5，按钮打开与监控页共用的添加弹窗。
- 右侧「直播中」列固定 280px 高，列表改用 Arc `ScrollArea`（垂直、overlay 滚动条、上下边缘渐隐），可添加房间多于可视高度时在列内滚动，不再截断为 4 条；「查看全部」仍打开侧栏。
- 没有可添加的直播房间时，右侧分栏显示紧凑空态文案；整张卡片结构不变。
- 不再使用大封面卡片，不再有刷新按钮和底部三块特性说明。

### 播放器控制条

- 按 B 站直播 DOM/尺寸复刻：底部 56px 渐变、36px 控制行、30px 图标按钮、左右两组。
- 鼠标移动时出现，静止约 2.8s 自动收起；音量/弹幕面板或画质菜单打开时保持显示。
- 左：播放/刷新/音量/时间；右：画质（108px 文本触发器）、PiP、弹幕开关、弹幕设置、画面填充、全屏。
- 直播不绘制进度线；本地视频在 56px 区域顶部显示细进度线。
- 画质触发器无 chevron，菜单向上打开，菜单跟随应用浅/深色主题。
- 音量改为 B 站式竖向浮层：32×110px，顶部数值，2px 轨道、4px 已填充段、12px 圆形滑块。
- 画质菜单、音量、弹幕设置、格子菜单统一为 `.player-glass`：半透明主题面 + 22px 背景模糊 + 细描边/顶部高光 + 柔和投影，浅/深色主题自适应。
- 顶部格子标题栏加轻微顶部渐变，图标统一 30px 命中区。

### 播放器内弹幕设置

- 点击弹幕设置打开 298px 浮层，底部与控制条保持 1px 间距，对齐 B 站尺寸。
- 面板使用应用主题玻璃：浅色主题浅玻璃、深色主题深玻璃；结构对齐 B 站官方。
- 主面板：显示区域、弹幕密度（正常/较多/重叠）、不透明度、字体大小、弹幕速度；细轨 + 白色圆形滑块，显示区域/速度带 5 个圆点刻度。
- 选中态使用应用 accent：滑杆填充、密度当前项文字、勾选框与文字；其余标签/数值跟随主题 ink/muted。
- 「弹幕随屏幕缩放」用 12px 方形勾选框；底部「高级设置」进入二级面板，目前提供恢复默认（B 站字体/描边选项暂未支持）。
- 点视频或再次点弹幕设置收起。

## 6. 添加直播间弹窗复用

- 新增 `src/features/monitor/AddRoomDialog.tsx`，把监控页原来的弹窗表单（链接输入、监控/自动录制开关、取消/添加按钮）抽成共享组件。
- 监控页只保留 `addOpen` 与列表刷新：`<AddRoomDialog open onOpenChange onAdded={() => load()} />`。
- 观看页的两个入口都直接打开同一弹窗：0 路空态左侧的「添加直播间」，以及侧栏底部的整宽「添加直播间」按钮。
- 观看页添加成功后：先刷新房间列表；若返回房间正在直播，直接 `watchRoom` 开一格；离线房间只进监控列表，不占格。
- 弹窗内的输入与开关状态由组件自己管理，关闭即重置；成功/失败提示沿用监控页文案。
- 原来的「粘贴链接 + 添加并观看」内联表单删除，对应 `watch.inputPlaceholder` / `watch.addAndWatch` 文案一并移除。

## 8. 已知限制

- **桌面 hover 放置**：悬停列表行出现格子浮层；触屏没有 hover，会走「直接加入空闲格」。
- **候选列表只显示直播中且未加入的房间**：筛掉已加入/离线房间，因此有时看起来「没有可添加的」。
- **槽位上限仍是 4**：移除计数不代表取消限制；满 4 路时仍会 toast。
