# 114-观看播放器控制细节优化

> 状态：v1 已实施（2026-11-09）；浅色主题浏览器预览完成音量、弹幕面板和工具按钮复看。
> 范围：观看格右上角菜单、音量浮层、弹幕面板节点与三个播放器工具按钮。

## 0. 结论速览

- 移除右上角格子菜单里的「铺满格子」项。画面适配已经由播放器底栏按钮负责，菜单中重复。
- 音量浮层从浅色玻璃胶囊改为与弹幕面板一致的深色面：`rgba(33,33,33,.9)`、8px 圆角、10px 背景模糊。
- 音量数值、轨道、白色滑块与弹幕面板统一；填充轨道保持项目蓝。
- 弹幕面板移除滑杆刻度节点，以及密度分段之间的竖分隔线。
- 弹幕设置、画面适应、全屏改用统一描边的 Lucide 图标：滑杆设置、适应画面、四角全屏。
- 三个按钮保留 30px 命中区；打开弹幕设置或启用铺满时，图标使用当前主题选中色。

## 1. 移除重复入口

格子右上角 `…` 菜单现在只保留：

- 与下一格交换（仅多格时显示）。
- 移出观看。

画面适配不再从右上角菜单切换，统一使用播放器底栏的适应/铺满按钮。对应 `watch.fill` 文案删除。

## 2. 音量浮层

| 项 | 实现 |
| --- | --- |
| 尺寸 | 44×128px |
| 背景 | `rgba(33,33,33,.9)` |
| 圆角 | 8px |
| 模糊 | 10px，与弹幕面板一致 |
| 数值 | 11px，白色 94% |
| 轨道 | 2px，白色 24% |
| 已填充轨道 | 4px，项目蓝 `#2f6bff` |
| 滑块 | 14px 白色圆形 |

浮层仍从音量按钮上方展开，鼠标离开按钮区域后收起。

## 3. 弹幕面板节点清理

- 显示区域、不透明度、字体大小、弹幕速度的滑杆不再绘制 5 个刻度节点。
- 正常 / 较多 / 重叠三个密度选项之间不再显示竖分隔线。
- 面板尺寸、20px 内边距、37px 行高和底部高级设置入口保持不变。
- 浅色主题选中文字仍为项目蓝，深色主题为项目黄。

## 4. 工具按钮优化

- 弹幕设置：`SlidersHorizontal`，打开面板时蓝色/黄色选中。
- 画面适应：`Scaling`，铺满模式开启时蓝色/黄色选中。
- 全屏：`Maximize2`，保持白色线性图标。
- 图标统一 22px、1.8px 描边；悬浮时轻微放大到 1.05，并保留 30px 命中区。

## 5. 验证

- 浏览器预览：音量浮层实测 44×128px、背景 `rgba(33,33,33,.9)`、圆角 8px。

- 浅色主题下弹幕设置按钮打开时图标颜色为 `rgb(47,107,255)`。
