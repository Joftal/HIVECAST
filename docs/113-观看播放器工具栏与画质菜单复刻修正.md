# 113-观看播放器工具栏与画质菜单复刻修正

> 状态：v1 已实施（2026-11-09）；浏览器预览完成控制条、画质菜单和弹幕面板复看。
> 范围：观看页直播播放器的底栏图标、尺寸、间距、画质入口与画质菜单。

## 0. 结论速览

- 底栏从 Tailwind 近似尺寸改成 B 站实测的固定几何：36px 操作行、30px 命中区、24px 图标、4px 间距。
- 播放、刷新、音量、画中画、弹幕、弹幕设置、画面适配、全屏全部换用 B 站当前控制区的 SVG 轮廓。
- 画质入口固定 108×30px、14px 字号，不再使用应用通用 Dropdown 触发器。
- 画质菜单从浅色玻璃 Dropdown 改为 B 站式 180px 深色面板：8px 内边距、8px 圆角、36px 行高。
- 线路仍从菜单顶部「当前线路」入口进入，避免把全部线路和全部画质堆成一张超长白色菜单。
- B 站粉色继续替换为项目主题色：浅色主题的选中文字和勾选用蓝 `#2f6bff`，深色主题切换为黄 `#f0a23c`。

## 2. 图标与交互

- 左侧按播放/暂停、刷新、音量、观看时长排列。
- 右侧按画质、画中画、弹幕开关、弹幕设置、画面适配、全屏排列。
- 图标直接采用 B 站当前播放器的 24×24 SVG 轮廓，替换此前的细线占位图标。
- 弹幕设置图标保留气泡主体，右侧小勾使用项目黄。
- 悬浮态使用 10% 白色底；弹幕工具按钮不再出现整块蓝色选中底板。
- 控制条仍在指针静止 2.8 秒后收起，菜单或弹幕面板打开时保持显示。

## 3. 画质菜单

- 触发器固定显示当前画质，宽度 108px，超长文案省略。
- 面板固定在触发器上方 2px，宽 180px，向上展开。
- 有线路数据时，顶部显示当前线路和右箭头；点击后在菜单内切换为线路列表。
- 画质列表只显示品质档位；自动档单独放到底部，用分隔线与手动档位区分。
- 当前线路与当前画质使用主题选中色；鼠标悬浮行使用 8% 白色底。
- 画质选中文字和播放器设置勾跟随主题：浅色蓝、深色黄。
- 菜单打开时关闭弹幕设置面板，避免两个浮层重叠。

## 4. 验证

- 浏览器 `?player-lab` 预览中控制区实测高 36px、左右内边距 12px。
- 画质入口实测 108×30px、14px 字号。
- 画质菜单实测 180px 宽、8px 内边距、8px 圆角、背景 `rgba(33,33,33,.9)`。
- 弹幕面板仍为 298px 宽，打开时画质菜单会关闭。
- `pnpm exec tsc -b` 通过。

## 5. 已知限制

- 本次复刻目标是 B 站桌面网页直播播放器，不包含 B 站客户端独有按钮。
- 画质增强开关未接入，因为 HIVECAST 当前没有对应后处理能力。
