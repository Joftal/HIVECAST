## 四、上线前最终行动清单（按平台与环境分工）

### 4.1 正式公开上线前的硬门禁（P0）

1. **GitHub Actions Dry-run**：在仓库手动触发 [.github/workflows/build-release.yml](../.github/workflows/build-release.yml)（`publish=false`，如 `0.1.0-rc.1` / `prerelease=true`），确认 `set-version.mjs` 注入、macOS/Windows 矩阵构建、挂载 DMG 冒烟与产物上传全程通过。
2. **macOS 公开签名、公证与带隔离属性首开（M9 / M10）**：在配置 Apple `Developer ID Application` 证书与公证 secrets 后执行 `HIVECAST_PUBLIC_MACOS=true`，逐项通过 `hdiutil verify`、`codesign --verify --deep --strict`、`xcrun stapler validate`（app 与 DMG）、`spctl --assess`（execute 与 open），并从浏览器下载同一哈希 DMG（保留 `com.apple.quarantine`）在干净用户下完成 Finder 首开与旧版覆盖升级验收。
3. **Windows 代码签名策略确认**：决定是否给 NSIS 安装器接入 Authenticode 签名；若 0.1.0 保持 `NotSigned`，在 Release Notes 中明确标注 SmartScreen 放行指引并公布最终 SHA-256。
