# 177 下线媒体库与房间录制文件入口

> 日期：2026-11-19  
> 范围：前端信息架构、监控行/抽屉入口、已移除直播间、后端查询命令  
> 结论：媒体库 Tab 已移除，录制文件改为按直播间进入；历史录像与播放、转封装、合并、删除能力保留。

## 1. 背景

旧媒体库是一个全局页面：顶部主播墙、平台筛选、全局搜索、批量多选、底部批量操作条，再叠加场次列表与播放抽屉。对只有少量房间的用户，媒体墙没有价值；对房间多的用户，又必须先找到主播再找场次，路径比“进入直播间看它的录像”更长。

本次按 B 方案改造：

- 顶栏删除「媒体库」，只保留监控、观看、任务。
- 监控行尾 `...` 与直播间详情抽屉都提供「录制文件」。
- 新页面只展示当前直播间的场次，不再有主播墙、跨房间搜索、平台筛选、批量多选。
- 移除直播间后，录像不会失去入口：监控底部保留「已移除 N · 历史录像仍保留」，可查看或恢复。

## 2. 信息架构

```text
监控
├─ 行尾 ... → 录制文件
├─ 直播间详情 → 录制统计 → 录制文件
└─ 底部「已移除 N」
   └─ 已移除的直播间
      ├─ 录制文件（只读历史）
      └─ 恢复（重新进入监控）
```

新页面 `src/features/media/RoomRecordingsPage.tsx`：

- 页头：返回监控、头像/首字母、主播名、平台 Chip、直播间标题、房间号、刷新。
- 工具条：标题/文件名搜索、全部时间/今天/近 7 天/近 30 天、仅看弹幕、按时间/时长/大小排序。
- 场次卡片：封面、平台/后处理角标、时长、弹幕数、标题、日期、体积；多片段场次显示「合并本场 N 段」。
- 播放覆盖层：本地 HLS 回放、弹幕轨、转 MP4、导出 ASS、在 Finder 中显示、删除。

不再包含：主播墙、平台筛选、全选、批量转 MP4/导出/删除/合并、跨房间搜索。

## 3. 后端改动

### 3.1 已移除直播间

`src-tauri/ipc-types/src/lib.rs`：

- `RoomRecord` 增加 `removed_at: Option<i64>`（Unix 秒，`#[ts(type="number")]`）。
- 新增 `RemovedRoom { room, session_count, total_bytes }`。

`src-tauri/src/db.rs`：

- `ROOM_SELECT` 增加 `removed_at`，`map_room` 读取第 38 列。
- `list_removed_rooms()`：`WHERE removed_at IS NOT NULL ORDER BY removed_at DESC`，按 `COUNT(DISTINCT COALESCE(group_id, id))` 统计场次、`SUM(file_size)` 统计体积。
- `restore_room(id)`：清空 `removed_at`、恢复 `monitor_paused=0`、`last_checked_at=NULL`，让下一轮监控马上检查。
- 删除主播墙查询 `MediaHostFilter`、`host_where`、`Db::media_hosts`、`host_counts_locked` 及其测试。

`src-tauri/src/commands.rs` / `lib.rs`：

- 新增 `removed_rooms`、`room_restore(id)` 两个 IPC 命令；恢复后 `broker.invalidate` 并广播 `rooms-changed`。
- 删除 `media_hosts` 命令。

软删除本身仍保留 `removed_at` 与 `monitor_paused=1`，历史 `record_session` 不删；恢复只是把房间重新放回监控列表。

### 3.2 兼容修正

`RoomRecord` 新增字段后，补了 6 处 Rust 初始化：`commands.rs`、`douyin_follow.rs`、`monitor.rs`、`recorder.rs`（两处）等，避免构造失败。

## 7. 边界

- 已移除房间的录像按房间 ID 查询，恢复后不会复制或移动文件。
- 移除房间只做软删除与停止监控，不删录像；真正的文件删除仍在录制文件页按场次执行。
- 「合并本场 N 段」只对同一 `group_id` 的多片段场次显示；合并产物 `reason=merge` 仍禁止再次参与合并。
- 新页面不提供跨房间批量操作；需要批量清理时按房间逐个进入。
- 已移除入口只在存在 `removed_at` 记录时显示，不占用正常监控列表空间。
