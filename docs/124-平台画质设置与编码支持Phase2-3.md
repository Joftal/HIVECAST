# 124-平台画质设置与编码支持（Phase 2/3）

> 状态：v1 已实施（2026-11-09）；监控详情改用平台画质清单，B 站/虎牙/抖音按编码能力开放或禁用。
> 范围：监控详情画质/线路选择、观看编码门禁、B 站/虎牙/抖音能力清单、设置页全局默认说明。

## 0. 结论速览

- **Phase 2**：监控详情的录制/观看画质选择改用 `room_stream_options`，直接显示平台真实档位；线路名称也改为平台真实名称 + 画质 hint。
- 设置页的全局默认画质保持通用名称：它同时作用于四个平台，没有单一平台上下文；具体平台档位在房间级选择器里展示。
- **Phase 3**：`QualityInfo.codec` 现在带真实视频编码；观看页用 MSE 能力检测决定 HEVC/AV1 档位是否可选。
- B 站按 `accept_qn` 反推每档支持的编码：优先 H.264；仅 HEVC/AV1 的档位在浏览器不支持时禁用并提示。
- 虎牙 H.264 档位正常可选；4K/2K HDR（HEVC）列在清单里但禁用，提示「当前链路暂不支持」。
- 抖音按平台返回的编码门禁；斗鱼当前只有 H.264。
- B 站杜比档位禁用，提示「杜比音频暂不支持」。
- 录制画质不受浏览器编码能力限制；只有**观看画质**和**监控详情的观看画质**做 MSE 门禁。

## 1. Phase 2：监控详情

### 加载

- 详情抽屉打开后，首次展开任一画质选择器时调用 `room_stream_options(roomId, recordQn)`。
- 同一房间同一 qn 复用缓存；线路刷新按钮会强制重新拉取。
- 结果同时填充画质列表和线路列表，避免两次平台请求。

### 展示

| 控件 | 数据 |
| --- | --- |
| 录制画质 | 平台真实名称 + 码率/编码 hint；`available=false` 的档位禁用 |
| 观看画质 | 同上，并额外做浏览器编码门禁 |
| 录制线路 | `line.name` 作为名称，`line.quality` 作为 hint |

- 列表第一位固定是「自动」。
- 当前 qn 不在平台清单时（例如旧配置 40000/20000），补一个同值兜底项，确保触发器有标签。
- 平台清单请求失败时回退到原有通用 `QUALITIES`，不阻塞设置。

### 设置页

- 全局「录制画质 / 观看画质」继续使用通用 qn 名称：它是跨平台默认值。
- 房间级选择器才展示平台真实档位；两者共用同一 qn 持久化值。

## 2. Phase 3：编码能力

### 后端

- `QualityInfo.codec`：`h264` / `h265` / `av1` / `unknown`。
- B 站：把每个 codec 的 `accept_qn` 汇总成 qn→编码集合；有 H.264 就标 H.264，否则 HEVC/AV1。
- 虎牙：
  - `iCodecType=0` 的 H.264 档位保持可选。
  - `iCodecType=1` 的 4K/2K HDR 档位加入清单，但 `available=false`，hint 说明「HEVC · 当前链路暂不支持」。
  - 4K HDR / 4K / 2K HDR / 2K 使用独立的展示 qn，避免与 H.264 档位合并。
- 抖音：使用 `collect_qualities()` 已解析的编码。
- 斗鱼：当前请求固定 `hevc=0`，清单标 H.264。
- B 站杜比（30000）：`available=false`，提示「杜比音频暂不支持」。

### 前端

新增 `src/lib/codecSupport.ts`：

- `videoCodecSupported()` 使用 `MediaSource.isTypeSupported()` 检测 `hvc1/hev1` 与 `av01`。
- H.264/未知编码默认兼容。
- `codecLabel()` 输出 H.264 / HEVC / AV1。

观看页：

- 档位 `disabled = !available || !videoCodecSupported(codec)`。
- 不支持时提示「当前播放链路不支持 HEVC」。
- 自动/当前档位兜底项不受门禁影响。

监控详情：

- 录制画质只按 `available` 禁用（ffmpeg 录制不受浏览器 MSE 限制）。
- 观看画质同时按 `available` 和 MSE 编码支持禁用。

## 3. 平台表现

| 平台 | 可选 H.264 | HEVC/AV1 处理 |
| --- | --- | --- |
| B 站 | 流畅/高清/超清/蓝光/原画等 accept_qn 内档位 | 仅 HEVC/AV1 的 2K/4K 档位按 MSE 支持开放；杜比禁用 |
| 斗鱼 | 原画/蓝光4M/超清/高清 | 当前请求固定 H.264，无 HEVC 档 |
| 虎牙 | 蓝光10M/蓝光4M/超清/流畅 | 4K/2K HDR 显示但禁用，等待 HEVC 链路 |
| 抖音 | 平台返回的 H.264 档 | 平台返回 HEVC/AV1 时按 MSE 支持开放 |

## 4. 已知限制

- 虎牙 HEVC 与 B 站杜比已在 [126](126-全平台画质可用性改造.md) 开放选择；能否取到仍取决于账号权限与浏览器解码能力。
- 设置页全局默认仍是通用名称；平台级名称只在房间/观看上下文中显示。
- 线路名称已改为平台真实名称；B 站 host 较长时会在菜单里省略。
- 旧 qn 40000 / 20000 / 15000 仍可持久化；能力清单会用平台实际档位展示。
