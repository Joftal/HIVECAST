## 1. 测试背景、范围与安全保护策略

在 [docs/211](211-四平台真机全功能全流程测试计划与验收标准.md) 中，四平台主流程通过手动粘贴浏览器 Cookie 完成验收；但 B 站与斗鱼的**扫码登录专属能力**（B 站 `ac_time_value` 自动续期令牌、斗鱼 `LTP0 + dy_did` 长期加密凭证、虎牙扫码 `udb_cred + device_id` 凭证及全三平台 `一键检查续期` 闭环）只有真实扫码登录后才能触发。

### 1.1 测试安全分级策略（零误删、零失步）

1. **前置冷备**：测试启动前已对 `~/Library/Application Support/com.hivecast.desktop/hivecast.db`（WAL 完整快照）与 `secret.bin` 执行只读冷备。
2. **续期巡检在真实主库执行（防令牌失步）**：`TC-QR-02` ～ `TC-QR-04`（查看账号页 UI、单平台手动检查续期、三平台 `一键检查续期`）直接在主配置实例中执行，确保上游一旦触发真实 Cookie/令牌轮换，新凭据立即同步写回主库，绝不造成旧令牌失效。
3. **拉流/录制/重开弹窗/覆盖与退出均在独立克隆沙盒执行（零污染）**：完成续期巡检后，将同步后的 `hivecast.db` 与 `secret.bin` 克隆至独立临时目录 `/tmp/hc-qr-e2e-mac/data`（配合独立 `HIVECAST_MEDIA_DIR`、`HIVECAST_CACHE_DIR`、`HIVECAST_LOG_DIR`），在沙盒内执行拉流、录制、重启、扫码弹窗取消、隐藏暂停轮询、手动 Cookie 覆盖清理旧 `LTP0` 及退出登录联动清理测试，**绝不触碰用户真实房间列表、录像目录或登录态**。
4. **脱敏红线**：全过程脚本、日志核查与最终报告严禁输出任何原始 Cookie、`ac_time_value`、`LTP0`、`udb_cred`、`qrcode_key` 等敏感值。

## 3. 实测执行结果与结论

### 3.1 总体结论

- **验收结论**：**全部通过（12 / 12 PASS，0 缺陷）**。
- **核心验证闭环**：
  1. **三平台扫码凭据与长期令牌双表加密落盘**：B 站（含 `ac_time_value`）、斗鱼（`credential_secret` 加密落盘 `LTP0` + `dy_did`）、虎牙（`credential_secret` 加密落盘 `udb_cred` + `device_id`）全部采用 `enc:v1:` 加密存储；账号页顶部显示 `已登录 3 / 4`、`未登录 1`，三平台均处于 `refreshable=true` 且零「自动续期不可用」警告。
  2. **真实线上自动续期实测成功**：单平台逐一点击「检查」及顶部「一键检查续期」均通过；其中**斗鱼真实触发了上游 `LTP0 + dy_did` 令牌轮换**（`outcome='refreshed'`、`message='已自动续期'`，新 Cookie 密文同步回写主库 `1799B -> 1783B`），B 站与虎牙均顺利完成线上探活（`outcome='fresh'`）。
  3. **扫码态高画质解锁与三路并发真录制**：B 站、斗鱼、虎牙扫码态关注列表秒级拉出，B 站解锁 `杜比 / 原画 / 蓝光` 与 6 条 `gotcha` FLV/TS/HLS 主备 CDN 线路；3 路并发真直播录制均 `status='finished'`，`ffprobe` 校验全部为完整 `1920×1080 H.264 + AAC` 双轨，配对 `.jsonl` 与 `.ass` 弹幕完整落盘。
  4. **生命周期边界与安全防护**：冷启动正确解密 3 份扫码凭据并触发 B 站启动复验；已登录态重开扫码弹窗并取消（含虎牙切 Cookie Tab 触发后端取消会话）不破坏原有凭据；窗口关闭隐藏至后台 6 秒期间 `qrcode/poll` 轮询完全暂停（0 次请求），窗口重新唤起后自动恢复轮询；手动 Cookie 覆盖斗鱼时自动清空旧 `LTP0` 且不影响虎牙；二次确认退出登录级联清空 `credential` / `credential_secret` / `credential_refresh` 三表无残留；全程运行日志零明文敏感令牌泄露且 `qrcode_key=***` 脱敏生效。
- **用户真实环境完整性核验**：测试结束后核查用户主库 `~/Library/Application Support/com.hivecast.desktop/hivecast.db`，B 站、斗鱼、虎牙 3 条 `status='ok'` 扫码凭据与斗鱼/虎牙 2 条长期加密凭证完整保留（含斗鱼刚轮换的新 Cookie），零残留 `hivecast` 进程，全部临时沙盒与冷备目录已清理。
