# 118-播放器控件统一与统计位置调整

> 状态：v1 已实施（2026-11-09）；浏览器预览完成 Checkbox、菜单高亮和弹层展开复看。
> 范围：弹幕面板选择框、播放器浮层展开/选择反馈、观看统计位置。

## 0. 结论速览

- 「弹幕随屏幕缩放」和高级设置里的「粗体」都改用 Arc Checkbox。
- Checkbox 使用 24px 命中区、18px 方块、弹簧勾选和 theme-aware 填充色。
- 播放器画质菜单、弹幕面板和音量浮层统一采用监控操作栏的弹性展开表现。
- 画质/线路菜单增加跟随指针和键盘焦点移动的共享高亮。
- 播放器左下角的 `分辨率 · 丢帧` 已移出视频画面，放到格子标题栏关闭按钮左侧。

## 1. Arc Checkbox

两个布尔选择都使用 `src/components/arc/checkbox`：

| 控件 | 位置 | 状态来源 |
| --- | --- | --- |
| 弹幕随屏幕缩放 | 弹幕主面板底部 | `danmakuPrefs.scaleWithScreen` |
| 粗体 | 更多弹幕设置 → 弹幕字体行 | `danmakuPrefs.bold` |

- 命中区：24×24px。
- 可视方块：18×18px。
- 选中填充：浅色主题项目蓝，深色主题项目黄。
- 勾选、方块缩放和 indeterminate 形变沿用 Arc 原生弹簧。
- 标签文字可点击，悬停/按下反馈由 Arc Checkbox 提供。

## 2. 展开与选择表现

播放器内的非模态浮层统一使用监控操作栏的交互节奏：

- 展开：从触发器方向 `scale(.97) + translateY(5px) + opacity(0)` 进入。
- 收起：缩小到 `.985`、下移 3px、淡出 160ms。
- 使用 `spring(stiffness: 520, damping: 44)`，与 Arc 操作栏的响应弹簧一致。
- 减少动态效果时直接显示，不执行弹簧动画。

画质与线路菜单额外增加共享高亮：

- 指针进入或键盘聚焦菜单项时，高亮块移动到对应行。
- 高亮使用 `spring.snappy`，不会逐项闪烁。
- 当前选中项继续使用主题色文字确认。
- 画质选项按监控操作栏的规格左对齐：按钮内左边距 11px，文字从整行高亮内部同一起点开始。

## 3. 播放统计位置

Player 新增 `showStats` 和 `onStatsChange`：

- 观看页传入 `showStats={false}`，避免统计继续覆盖视频左下角。
- 每秒统计通过 `onStatsChange` 上送 `PlayerStats`。
- SlotCell 在标题栏关闭按钮左侧显示：
  - 分辨率，例如 `1280x720`。
  - 有丢帧时追加 `· 丢帧 N`。
- 统计随标题栏一起仅在实际悬浮/聚焦观看格时显示。
- 播放器卸载或换流时上送 `null`，避免旧统计残留。
