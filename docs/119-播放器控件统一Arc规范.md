# 119-播放器控件统一 Arc 规范

> 状态：v1 已实施（2026-11-09）；浅色与深色主题浏览器预览完成弹幕面板、画质菜单、音量浮层复看。
> 范围：观看页播放器底栏、弹幕设置面板、画质/线路菜单、音量浮层。

## 0. 结论速览

- 弹幕密度、描边类型改用 Arc `Segmented`，字体族改用 Arc `SelectMenu`，恢复默认改用 Arc `Button`，粗体与随屏幕缩放继续使用 Arc `Checkbox`。
- 画质/线路菜单从自绘 `PlayerQualityMenu` 换成 Arc `DropdownMenu`（`variant="video"`），线路与画质合并为一组菜单项，选中项带勾并与监控页一致支持共享滑动高亮。
- 弹幕面板与音量浮层从固定深色面改为主题玻璃：浅色主题白玻璃、深色主题暗玻璃，文字/描边/滑轨全部走 `--c-surface / --c-line / --c-ink / --c-accent`。
- 删除 `src/features/watch/PlayerQualityMenu.tsx` 与 `player-controls.css` 中整段 `.player-quality*` 自绘样式。
- 保留视频覆盖层专用的自绘控件：30px 图标按钮、进度条、竖向音量滑杆、面板行导航按钮；它们只对齐尺寸与焦点/主题色，不替换为表单控件。
- `tsc -b`、`pnpm build`、`check:i18n`（735 keys）、`check:docs`（120 files）通过。

## 1. 控件审查清单

| 控件 | 位置 | 处理 | 说明 |
| --- | --- | --- | --- |
| 播放/重连/音量/画中画/弹幕/弹幕设置/画面适配/全屏 | 底栏 | 保留 `PlayerButton` | 视频覆盖层按钮需要 30×30px 命中区、24px 图标与白色描边，Arc Button 的表单高度会破坏 B 站几何；保留自定义但尺寸、圆角、焦点与主题色对齐监控规范 |
| 画质 + 线路 | 底栏 108×30px 入口 | Arc `DropdownMenu` | `variant="video"`、`side="top"`、`align="end"`，菜单主题玻璃、选中勾、共享高亮；删除自绘菜单 |
| 进度条 | VOD 控制条顶部 | 保留原生 range | 直播无进度线；仅本地录像显示，透明 input 叠在自绘轨道上 |
| 音量滑杆 | 音量浮层 | 保留竖向滑杆 | 媒体专用竖向交互；轨道、填充、滑块改为主题 token |
| 显示区域/不透明度/字体大小/速度 | 弹幕主面板 | 保留原生 range | 37px 行高与 298px 面板几何不变，轨道与滑块使用主题色 |
| 弹幕密度 | 弹幕主面板 | Arc `Segmented` | 正常/较多/重叠，整宽三等分 |
| 弹幕随屏幕缩放 | 弹幕主面板底部 | Arc `Checkbox` | 24px 命中区，主题 token |
| 弹幕字体 | 高级设置 | Arc `SelectMenu` | 黑体/宋体/楷体，替代原生 `<select>` |
| 粗体 | 高级设置 | Arc `Checkbox` | 主题 token，选中标签用 accent-text |
| 描边类型 | 高级设置 | Arc `Segmented` | 重叠/描边/45° 投影，整宽三等分 |
| 恢复默认设置 | 高级设置底部 | Arc `Button` | `size="sm" variant="ghost"` |
| 更多弹幕设置 / 返回 | 面板底部与高级面板顶部 | 保留行导航按钮 | 整宽 40px 列表行，带 chevron，属于面板结构而非表单动作 |
| 画质菜单滚动 | 画质菜单 | 主题玻璃 + 限高 | 最大宽度 17rem、最大高度取 Radix 可用高度，线路域名超长时省略 |

## 2. 画质与线路菜单

- 触发器：108px 宽、30px 高，文字居中，无 chevron，悬停/打开使用 10% 白色底板，与 B 站画质入口一致。
- 菜单项顺序：先线路（「线路 · 自动/线路 1…」），分隔线后为具体画质，最后是「自动（当前实际画质）」。
- 线路与画质各自保留选中勾，因此可能出现两个勾：一个表示当前线路，一个表示当前画质。
- 菜单主体使用 `DropdownMenu` 的共享高亮，指针与键盘焦点都会移动同一块高亮；选中项文字保持主题强调色。
- 菜单宽度上限 17rem，线路域名在行尾省略，避免窄分屏里菜单被推到触发器之外。
- 菜单背景与会话弹幕面板统一为 78% 主题表面 + 22px 背景模糊；深色主题自动切到暗玻璃。

## 3. 弹幕面板

- 面板宽 298px、左右 20px 内边距、37px 滑杆行保持不变。
- 密度与描边使用 `Segmented` 的 `fullWidth` 变体：背景 `bg-raised`、选中滑片 `bg-surface`、选中文字 `text-ink`，浅色/深色主题自动适配。
- 高级设置字体行：`SelectMenu` 宽 154px，右侧为粗体 Checkbox。
- 面板表面：`color-mix(--c-surface 78%)` + 1px 主题描边 + 22px 模糊；减少透明度模式下回退为不透明 `--c-surface`。
- 恢复默认按钮放在 40px 底栏内，使用 Arc Button ghost，不再使用裸 `<button>`。

## 4. 音量浮层

- 尺寸保持 44×128px、竖向 92px 滑轨。
- 背景改为主题玻璃，数值与焦点提示使用 `--c-ink` / `--c-accent`。
- 轨道使用 20% ink，填充使用 `--c-accent`，滑块使用表面色加细描边，避免浅色主题下白滑块消失。
- 减少透明度模式下回退为不透明表面。

## 5. 与监控页规范的对应

| 监控页规范 | 播放器对应 |
| --- | --- |
| `DropdownMenu iconOnly variant="bare" size="sm" align="end"` | 画质入口使用 `variant="video"`，保留 108×30px 几何，菜单行为与共享高亮一致 |
| Arc `Checkbox` | 随屏幕缩放、粗体 |
| Arc `Switch` / `Button` | 播放器没有布尔开关表单；恢复默认使用 Arc Button |
| Arc `SelectMenu` | 弹幕字体 |
| Arc `Segmented` | 弹幕密度、描边类型 |
| 主题 token（surface/line/ink/accent） | 弹幕面板、画质菜单、音量浮层 |

## 6. 保留的自定义控件与原因

- `PlayerButton`：覆盖在视频上的图标按钮需要固定 30px 命中区与白色线性图标，Arc Button 的高度、圆角和文字内边距不适用于播放器底栏。
- 进度条与音量滑杆：媒体专用交互，沿用原生 range 以获得拖拽、键盘与触屏行为。
- 弹幕面板滑杆：与进度条共用 `.hv-range` 轨道样式，仅替换颜色 token。
- 弹幕面板行导航按钮：整宽列表行（标签 + chevron），属于面板结构，不承担表单提交。
