发布链路另有一处**基线已有的差异**。发布工作流对任意稳定版传 `gh release create --latest`，而站点和客户端按 SemVer 选择最高版本。以后若先发布 2.0.0、再回补 1.1.9，GitHub 的 Latest 与客户端推荐会不同。现有站点用例只验证了后两者。发布维护版本时应统一三端规则。见 `.github/workflows/build-release.yml:379`、`scripts/ci/generate-changelog-site.mjs:1434`。
