# 108-监控列表备注与标签内联编辑

> 状态：v1 已实施（2026-11-09）；前端编译与构建通过，真实窗口的列宽/内联编辑体验待复看。
> 范围：监控列表新增独立的「备注」「标签」列，点击直接内联编辑，不打开录制详情；标签使用 Arc TagInput。
> 前置阅读：`106-录制详情控制台增强.md`、`107-复杂设置接入Arc-Tooltip.md`。

## 0. 结论速览

- 备注从主播列拆成独立列；点击直接变成输入框，Enter/失焦保存，Escape 取消。
- 标签独立成列；点击进入 Arc `TagInput` 紧凑版，Enter 或逗号添加，失焦保存。
- 备注无内容时显示「添加备注」，标签无内容时显示「添加标签」；不再显示「本地」标识。
- 保存只更新对应字段，通过 `toRulesInput` 保留标题规则、分片和通知覆盖。
- 搜索仍覆盖备注和标签；标签筛选和列表 chips 保持可用。

## 1. 备注列

- 组件：`features/monitor/InlineNote.tsx`。
- 展示态：按钮 + 单行截断文本；hover 出现铅笔图标。
- 编辑态：原生输入框，自动聚焦，`h-7`，与表格内其他小控件一致。
- 保存：Enter 或失焦；Escape 恢复原值并退出。
- 空值：显示 `monitor.addNote`（添加备注）；有值时直接显示主播本地 ID。
- 不再在主播列显示备注，也不再有 `localAlias`「本地」徽标。

## 2. 标签列

- 组件：`features/monitor/InlineTags.tsx`，底层是 Arc `TagInput`。
- 展示态：最多两个 chips + `+N`；空值显示「添加标签」。
- 编辑态：`TagInput compact autoFocus`，自动聚焦输入框。
- 键盘：Enter 或逗号添加；Backspace 选中/删除；Escape（输入为空时）保存退出。
- 失焦：点击单元格外保存；点击 tag 删除按钮仍留在编辑态。
- 保存：`tags.join(", ")`，与内部存储格式一致。

## 3. 列布局

`COLUMNS` 从 8 列变为 10 列：

```text
缩略图 / 直播 / 录制 / 平台 / 主播 / 备注 / 标签 / 画质 / 时长 / 操作
```

- 备注 120px，标签 140px，主播列继续用 `minmax(0,1fr)` 吸收剩余空间。
- 行高保持 76px；标签编辑态可能因换行临时增高，退出后恢复。
- 表头新增「备注」「标签」两列。

## 4. 数据写入

新增 `features/monitor/roomRuleInput.ts`：

```ts
toRulesInput(room, { note: next })
toRulesInput(room, { tags: next })
```

- 内联编辑不直接拼后端参数，而是复用房间当前规则，只覆盖目标字段，避免把标题/分片/通知规则清空。
- 写入仍走 `room_set_rules`，成功后广播 `rooms://changed`，列表与抽屉同步刷新。

## 5. TagInput 本地扩展

Arc TagInput 由 shadcn 注册表引入：

- 新增 `compact`：隐藏可见 label，压缩 content/tag/input 高度，适配表格单元格。
- 新增 `autoFocus`：点击单元格后直接输入。
- 其余键盘、重复标签脉冲、删除动画、aria-live 播报保持 Arc 原实现。

## 7. 已知限制

- **备注是单行输入**：不支持多行长备注；长文本在列表截断，完整值可在提示/详情中查看。
- **标签编辑可能撑高行**：标签较多时会换行，退出编辑后恢复 76px 行高。
- **失焦即保存**：点击页面其他位置会提交当前标签草稿；Escape 仅在输入为空时退出。
- **备注按房间保存**：当前一行对应一个主播房间；同一主播多房间暂不共享备注。
