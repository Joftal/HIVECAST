# 116-观看分屏标题与弹幕图标分工

> 状态：v1 已实施（2026-11-09）；浏览器预览完成弹幕开启、关闭与设置打开三态复看。
> 范围：观看格左上角标题区、弹幕开关图标、弹幕设置图标。

## 0. 结论速览

- 观看格左上角的分屏编号 `01–04` 已移除，标题区只保留拖拽点、头像和直播间标题。
- 弹幕开关改用独立字幕图标，不再使用带齿轮的“弹”字图标。
- 弹幕关闭时，字幕图标叠加斜线；按钮提示为「开启弹幕」。
- 弹幕设置恢复使用原来的带“弹”字图标，不再使用 Lucide 滑杆图标。
- 设置面板打开时，不再整块改变图标颜色，只在设置图标右上角显示主题色状态点。

## 1. 分屏标题

- 移除标题栏中的 `String(index + 1).padStart(2, "0")` 编号节点。
- 移除 `CellProps.index` 中仅用于编号展示的字段传递；交换格子仍使用内部索引，不影响拖拽和换位。
- 标题栏顺序改为：拖拽点、主播头像、直播间标题、状态与操作按钮。

## 2. 弹幕开关

| 状态 | 图形 | 提示 |
| --- | --- | --- |
| 开启 | 圆角字幕框 + 三行弹幕线条 | 隐藏弹幕 |
| 关闭 | 字幕框 + 斜线 | 开启弹幕 |

开关图标不再包含齿轮，避免与弹幕设置混淆。

## 3. 弹幕设置

- 使用原来的“弹”字弹幕图标，内部细节包含设置语义。
- 图标默认保持白色，不因面板打开而整块变成蓝色或黄色。
- 面板打开时，右上角出现 5px 状态点；状态点使用主题选中色：
  - 浅色主题：项目蓝 `#2f6bff`
  - 深色主题：项目黄 `#f0a23c`
- 状态点使用 160ms 弹簧缩放进入，关闭后缩回。

## 4. 验证

- 浏览器预览中弹幕开启、关闭、设置打开三种状态均显示不同表现。
- 设置面板打开时状态点 `opacity: 1`。
- 分屏编号节点已从标题区删除。
- `pnpm exec tsc -b`、`pnpm build`、`pnpm check:i18n` 737 keys 通过。
