# 117-观看格菜单移除与画面适配说明

> 状态：v1 已实施（2026-11-09）。
> 范围：观看格标题栏 `…` 菜单、适应画面与铺满格子的行为说明。

## 0. 结论速览

- 删除观看格标题栏右上角 `…` 按钮，以及“与下一格交换 / 移出观看”弹层。
- 格间交换继续通过拖拽标题栏完成；移出观看继续使用标题栏右侧的直接关闭按钮。
- “适应画面”和“铺满格子”都不会非等比拉伸视频。
- 两者都保持原始宽高比，区别只在于完整显示还是裁切边缘。

## 1. 菜单移除

- 删除 `menuOpen` 状态和 `onSwapNext` 属性。
- 删除 `watch.swapNext`、`watch.cellMenu` 文案。
- 保留 `watch.remove`，用于观看空态或其他仍需要移除房间的入口。
- 标题栏保留：拖拽点、主播头像、直播间标题、画质降级标记、直接关闭按钮。

## 2. 适应画面

对应 CSS：`object-fit: contain`。

画面按原始宽高比等比缩放，直到整幅画面都能放进格子。若视频比例与格子比例不同，未占满的区域显示黑边。

```text
完整画面优先
可能上下或左右留黑边
不裁切
不拉伸
```

适合需要看完整游戏 HUD、字幕或竖屏直播时使用。

## 3. 铺满格子

对应 CSS：`object-fit: cover`。

画面同样按原始宽高比等比缩放，但会一直放大到宽和高都覆盖整个格子，超出格子的部分被裁切。

```text
填满格子优先
不显示黑边
会裁切上下或左右边缘
不拉伸
```

适合横屏游戏直播、希望画面充分利用格子空间的场景。竖屏直播使用铺满时会裁掉更多上下内容。

## 4. 行为对照

| 模式 | 等比缩放 | 完整画面 | 黑边 | 裁切 |
| --- | --- | --- | --- | --- |
| 适应画面 | 是 | 是 | 可能出现 | 否 |
| 铺满格子 | 是 | 否 | 无 | 超出部分裁切 |

用户可以记住一个简单判断：

- **适应画面 = 看全，可能有黑边。**
- **铺满格子 = 填满，可能裁掉边缘。**
