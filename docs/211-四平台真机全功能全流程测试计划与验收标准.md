## 1. 测试目标、环境矩阵与安全红线

### 1.1 测试总目标

基于用户提供的四平台真实账号凭据（本地未追踪文件 `Cookie.txt`），在 **macOS 与 Windows 11 双端真机桌面环境** 下，围绕「**真账号、真直播流、真弹幕、真录制、真后处理、全界面层级、全设置项闭环**」开展上线前全量端到端（E2E）验收，确保：

1. **四平台核心链路 100% 跑通**：账号接入与状态巡检、关注列表拉取与导入、直播间状态轮询、实时多路分屏观看、手动/自动录制、无损分段切分、弹幕与礼物/SC/舰长落盘、后处理转封装/合并/导出、本地滑窗回放全部真实可用。
2. **所有 UI 层级零死角验证**：覆盖主窗口壳层（L1）、三大业务主视图与 8 大设置页（L2）、14 个二级子页面/弹窗/抽屉/浮层面板（L3）、以及二级高级面板/长按确认/放置选择器/行内编辑/异常横幅/空状态（L4）。
3. **40+ 设置项逐项真实生效**：不仅验证 UI 读写与数据库持久化，还逐项验证非法值拦截/边界夹取、悬浮 `ⓘ InfoTip` 说明展示，以及修改设置后对下游监控、观看、录制、弹幕、后处理、清理、通知、系统行为的**真实运行期影响**。
4. **异常与极端场景稳健自愈**：覆盖录制中途进程强杀重启恢复、后处理失败重试与取消、录制中关窗拦截与「任务完成后自动退出」、窗口高分屏几何状态记忆与托盘隐藏唤醒。

### 1.3 数据安全、凭据保护与防破坏红线

1. **真实用户数据零触碰**：
   - 执行前先对本机默认数据库 `~/Library/Application Support/com.hivecast.desktop/hivecast.db` 做只读冷备校验；
   - 全程仅在独立沙盒目录运行测试实例，绝不读写或污染本机/远端真实用户的历史数据库与录像目录。
2. **Cookie 凭据脱敏与防误注销红线**：
   - `Cookie.txt` 仅在内存中读取并剥离行首中文标签（`bilibili：`、`斗鱼：`、`虎牙：`、`抖音：`）后注入隔离测试库；
   - **严禁**将任何原始 Cookie 字符串、Token、`SESSDATA`、`bili_jct`、`acf_auth`、`udb_biztoken`、`sessionid` 等敏感值写入日志、截图、测试报告或 Git 仓库；
   - 验证「退出账号（删除本地凭据）」时，确认后端 `credential_delete` 仅删除本地隔离 SQLite 记录（不调用平台远端注销接口使浏览器 Cookie 失效），且先完成全部平台在线业务测试后，仅在一次性沙盒副本中验证本地凭据清除流程。
3. **平台礼仪与合规红线**：
   - 不执行任何充值、送礼、发弹幕、改关注关系等写操作，所有平台交互严格限定为**只读拉流、只读收包（弹幕/状态/关注列表）**；
   - 测试结束后彻底清理沙盒目录（含加密凭据库、临时录像、日志）及残留进程。
