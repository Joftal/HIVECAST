# 101-监控列表细节优化

> 状态：v1 已实施（2026-11-09）；编译与静态检查通过，真实房间的禁用态/懒加载效果需 Tauri 有数据时复看。
> 范围：监控列表的四项小修：列头文案、离线观看禁用、多选浮条留白、缩略图/头像懒加载。
> 前置阅读：`92-四页结构统一.md`、`95-监控行浮动按钮组.md`。

## 0. 结论速览

- 列头「录制时长」改为「录制时间」（英文 `Recording time`），和单元格里的日期 + 时长一致。
- 离线且没有录制中的房间，「观看」按钮禁用；详情抽屉里的大缩略图也同步禁用，不再发一次注定失败的 `viewOpen`。
- 有选中房间时，列表滚动区底部加 `pb-20`，避免最后一行被底部多选浮条遮住。
- 监控缩略图和头像补 `loading="lazy"` + `decoding="async"`，房间多时减少首屏图片解码。

## 1. 列头文案

| 位置 | 原来 | 现在 |
| --- | --- | --- |
| 监控表头最后一列前 | 录制时长 | 录制时间 |
| 英文 | Recorded | Recording time |

单元格本身显示「开始时间 + 时长」，列头原来的「录制时长」只描述了后半部分。

## 2. 离线观看禁用

- 行内 `FloatingButtonGroup` 的「观看」item 增加 `disabled: !room.isLive && !isRecording`。
- 详情抽屉顶部的大缩略图按钮同样 `disabled`，并加 `disabled:cursor-not-allowed disabled:opacity-60`。
- 录制中的房间即使平台状态短时为离线，仍允许观看；直播中正常允许。
- 禁用后不再调用 `openWatch`，避免一次「未开播」的 error toast。

## 3. 多选浮条留白

- 列表滚动容器：`min-h-0 flex-1 overflow-auto`，选中数量 > 0 时追加 `pb-20`。
- 底部浮条高度约 44px + 底部间距，80px 留白足够让最后一行完整露出。
- 没有选中时保持原有布局，空态居中不受影响。

## 4. 图片懒加载

| 位置 | 改动 |
| --- | --- |
| 行缩略图 `Thumb` | `loading="lazy"`、`decoding="async"` |
| 行头像 `Avatar` | `loading="lazy"`、`decoding="async"` |

监控页可能一次展示很多远程封面/头像；懒加载让首屏只解码视口附近的图片。

## 5. 验证

- `pnpm exec tsc -b`、`pnpm build` 通过；`check:i18n` 640 keys、`check:docs` 102 files。
- 无数据浏览器预览仍能正常渲染空态与筛选；列头/禁用态/图片属性需要 Tauri 真实房间复看。
- 选中 ≥1 个直播间时，最后一行可滚动到浮条上方。

## 6. 已知限制

- **懒加载依赖浏览器/WebView2 的原生行为**：已进入视口的图片仍会立即加载。
- **离线禁用只针对观看**：行尾刷新、暂停监控、自动录制、按住移除仍可用。
- **多选浮条留白是固定值**：如果浮条后续变高，需要同步调大 `pb-20`。
- **详情抽屉缩略图禁用后仍保留画面**：只是不可点击，方便查看上次封面。
