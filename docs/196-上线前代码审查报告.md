## 当前实现要点

- **分片生命周期**：录制按 `group_id` + 从 0 递增的 `clip_index` 建会话；收尾按完整路径前缀与数值编号收集分片，合并清单使用绝对路径；产物先写临时文件，校验通过后带写句柄刷盘并原子替换。
- **整组合并**：前端按组取全量片段，后端按 `clip_index`/`started_at` 排序，缺文件片段明确报告；合并目标原子预留，不覆盖旧文件。
- **保留策略**：过期或容量淘汰时先删成品、弹幕、字幕、清单、残留分片和 `media_file` 登记；任一删除失败就保留会话，下一轮可重试。容量按未删除登记求和。
- **设置保存**：媒体目录强制绝对路径；36 个键在单事务内提交；损坏或写失败不会留下半套配置。
- **自动录制取消**：关闭自动录制会写取消标记，取流计划生成后、进程启动前两次复核，避免关闭后仍起录。
- **任务中心**：阶段事件不再被孤儿清理误删；阶段/状态中英文标签由后端统一映射；事件检索支持中文标签、FTS5 与跨 Run CSV 导出。
- **播放与回放**：页面卸载会递增播放代次，迟到的 `mediaPlay` 结果被丢弃并释放；媒体保留失败不会让入口消失。
